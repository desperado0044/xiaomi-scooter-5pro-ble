# Security policy / Sicherheitshinweise

**English:** Please report security problems **privately** through GitHub
(*Security → Report a vulnerability*), not as a public issue. This app handles scooter access keys,
password-encrypted export/backup files and personal documents, so problems in the key storage, the
export/backup encryption or the app lock are especially relevant. Only the latest release is supported.
This is a non-commercial project without a fixed response time; I will answer as soon as I can.

**Deutsch:** Bitte Sicherheitsprobleme **nicht öffentlich** als Issue melden, sondern privat über GitHub
(*Security → Report a vulnerability*). Die App verwaltet Zugangsschlüssel des Scooters,
passwortverschlüsselte Export-/Sicherungsdateien und persönliche Dokumente; besonders relevant sind daher
Fehler bei der Schlüsselspeicherung, der Export-/Sicherungsverschlüsselung und der App-Sperre. Unterstützt wird
jeweils nur die neueste Version. Eine feste Antwortzeit gibt es bei einem nicht-kommerziellen Projekt nicht.

Never post keys, PINs, MAC addresses or export files in a public issue. /
Keine Schlüssel, PINs, MAC-Adressen oder Exportdateien in öffentlichen Issues posten.
