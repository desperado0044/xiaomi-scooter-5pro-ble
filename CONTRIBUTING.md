# Contributing / Mitwirken

**English**
- **Compatibility reports** are the most useful contribution: use the
  [compatibility report form](https://github.com/desperado0044/xiaomi-scooter-5pro-ble/issues/new?template=compatibility_report.yml)
  (especially for the standard Electric Scooter 5, which is untested).
- Bug reports and pull requests are welcome. For larger changes please open an issue first.
- **Never post** MAC addresses, access keys, PINs, export codes/files or screenshots showing them.
- Build: see the README ("Building"). Run the unit tests with `./gradlew testDebugUnitTest` from `android-app/`.
- Keep changes small and in the style of the surrounding code; new behavior should come with a test where practical.
- License: contributions are made under the project's
  [PolyForm Noncommercial License 1.0.0](LICENSE). Commercial use is not permitted (see README).

**Deutsch**
- **Kompatibilitätsberichte** sind der nützlichste Beitrag: bitte das
  [Formular](https://github.com/desperado0044/xiaomi-scooter-5pro-ble/issues/new?template=compatibility_report.yml) nutzen
  (besonders für den normalen Electric Scooter 5, der ungetestet ist).
- Fehlermeldungen und Pull Requests sind willkommen. Bei größeren Änderungen bitte vorher ein Issue eröffnen.
- **Niemals** MAC-Adressen, Zugangsschlüssel, PINs, Exportcodes/-dateien oder Screenshots davon posten.
- Bauen: siehe README („Bauen"). Unit-Tests: `./gradlew testDebugUnitTest` im Ordner `android-app/`.
- Änderungen klein halten und dem Stil des umgebenden Codes folgen; neues Verhalten möglichst mit Test.
- Lizenz: Beiträge stehen unter der [PolyForm Noncommercial License 1.0.0](LICENSE) des Projekts.
  Kommerzielle Nutzung ist nicht gestattet (siehe README).
